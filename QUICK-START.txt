----------------------
1. booking-backend/ - Full Node.js/Express backend API

4. Complete documentation and setup guides

💰 COST: £0/month + Stripe fees (2.9% + 20p per booking)

🚀 NEXT STEPS (30-45 minutes total)
-----------------------------------

STEP 1: Set up MongoDB (5 min)
→ Go to mongodb.com/cloud/atlas
→ Create free account & cluster
→ Get connection string
→ See: BOOKING-SYSTEM-SETUP.md (Part 1)

STEP 2: Configure Stripe (10 min)
→ Use your existing Stripe account
→ Get secret API key
→ Set up webhook
→ See: BOOKING-SYSTEM-SETUP.md (Part 2)

STEP 3: Generate Admin Password (2 min)
→ cd booking-backend
→ npm install
→ node utils/generatePasswordHash.js YOUR_PASSWORD
→ See: BOOKING-SYSTEM-SETUP.md (Part 3)

STEP 4: Create .env File (5 min)
→ Copy .env.example to .env
→ Fill in MongoDB URI, Stripe keys, password hash
→ See: BOOKING-SYSTEM-SETUP.md (Part 4)

STEP 5: Test Locally (5 min)
→ npm start
→ Open http://localhost:3000/admin
→ Login with your password
→ See empty dashboard (ready for bookings!)

STEP 6: Deploy (15 min)
→ Sign up at railway.app
→ Deploy your booking-backend
→ Add environment variables
→ Get your live URL
→ See: BOOKING-SYSTEM-SETUP.md (Part 6)

STEP 7: Update Website (10 min)
→ Add <script src="js/booking-api.js"></script> to booking.html
→ Test a booking
→ See it in admin dashboard!
